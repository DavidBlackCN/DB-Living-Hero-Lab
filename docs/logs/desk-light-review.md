# 左手、书本与桌面光影修正 — 2026-09-16

本轮基于 `a4f6d11`，处理人工指出的中午／夜间桌面异常，优先检查画面左侧的手。此前窗户边界与笔具遮挡不再改动。验收图见 [本轮截图索引](../screenshots/desk-light-review/README.md)。

## 原因与修正

1. **左手轮廓错位。** 旧 `handLeft` 从 `(604,492)` 开始，漏掉实际手腕、手掌与上方指节；它同时用于从衣服中排除皮肤和挖除桌面接收区。不同受光系数因此在手背内部形成多边形。按原图重新描绘外轮廓，并让手、书与桌面使用连续的接收覆盖，不再在手部挖洞。
2. **桌面覆盖穿过前景。** 桌面多边形没有扣除头发／衣服，夜间台灯光池沿桌面的上边界切过右侧袖子。生成接收图时按前后关系扣除人物，再加入手部；台灯的同一平滑光池也作用于前景袖子和头发，避免在穿过袖子的桌面边线处突然开启。
3. **整轮廓平移无法表示物体投影。** 旧 shader 根据太阳／台灯方向平移人物、书本、杯子轮廓，却没有投射物高度或接收面深度，产生落在书页、手部及桌面的重复轮廓。删除 `castCoverage`、偏移量及其对日照、环境光、台灯的多次压暗。保留窗框光带间的柔和暗区和光带外压暗。
4. **书本底部接触位置错误。** 旧阴影折线与书本实际下缘分离。校准完整书本轮廓和下缘，仅在暴露桌面上生成轻微接触阴影；强度上限从 30% 降到 12%，避免重复强化原画已有阴影。笔记本电脑从桌面接收区排除。

没有改变人物设计、原画像素或整体色温参数，没有新增调试参数／纹理／渲染 pass，也没有加入 UV 阈值补丁。

## 当前限制与 normal 状态

这次修复的是错误的区域分配和投影模型，normal 图本身无法修复这两类问题。配准 normal v1 已同步轮廓并复测，但仍为 `/?normal=registered` 的候选；普通 `/` 保留低频版本。现有 normal 只控制 directional light，对 projected light 与夜间台灯尚无表面方向响应，不能宣称换图后夜景已获得真实几何光照。

原图含有烘焙日照与接触阴影；目前保留这些细节，仅增加受约束的柔和光照。接触区域和头发／衣服轮廓仍为手绘近似，也没有高度场、真实遮挡射线或动态物理投影。后续 normal 精修应在本轮手部／桌面观感获认可后继续，不能用更复杂法线掩盖区域错误。本轮在此停下供人工验收。
