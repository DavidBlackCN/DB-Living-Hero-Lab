## 起点与范围

已读取根目录 AGENTS.md、REQUIREMENTS.md。起点只有两张素材、需求文档及空目录，没有应用代码、依赖清单或 Git 元数据。主图确认 3840×2160。原始素材未修改；kuro-standard.png 未用于运行背景。本阶段依据用户明确要求完成 bootstrap、时间系统、Lighting MVP，微动画留待后续。

## 小步实现记录

1. 建立 Vite / TypeScript 骨架与完整等比底图显示；首次 build / typecheck 通过。
2. 加入独立 Timeline、逐时段线性光系数与平滑插值。
3. 加入单 pass WebGL2 渲染、原图注册的程序性法线／遮罩、环境与窗光、暖灯池、脸部保护、曝光与高光柔化。
4. 原生 DOM debug panel 暴露时间、四预设、realtime、光照强度、法线、脸部保护、动画开关、reduced motion 与五种调试视图。
5. 补充纹理替换入口、资源释放、背景暂停、静止时停止绘制、DPR 上限、初始化错误回退与上下文丢失提示。
6. 加入时间边界、午夜过渡、实时模式、全天参数有效性和关键帧连续性测试，保存实际浏览器画面。

## 实施中修复

- 默认 npm 缓存无写权限，改用仓库内 `.npm-cache`；缓存已加入忽略规则。
- 最初通过 npm 传端口参数时被解析成 Vite 根目录，导致 404；修正为直接 `npm run dev` 后页面可访问。
- 修复 TypeScript 对 WebGL 上下文在闭包内的非空类型检查。
- 首帧 RAF 时间戳可能略早于 `performance.now()`，将 dt 下限设为 0，避免时间短暂反向。

## 视觉评价与限制

- 黎明：略冷的环境光，画面清晰柔和。
- 正午：接近原图，保持面部、发丝与服装细节。
- 黄昏：右侧窗光更暖，桌面和发侧有明显暖色响应。
- 夜间：冷环境与暖灯区可分辨，面部保持可读；窗外天空和原图日照痕迹仍偏日间。
- 近似遮罩不是精确人物分割，存在背景泄漏及局部影响范围不准；法线缺少真实表面结构和遮挡。
- 光源只在实际窗侧小幅改变方向，没有地理位置、季节、太阳天文模型。
- 当前只有时间变化带来的动态，没有独立微动画；不宣称完成后续全部 Living Hero 阶段。
- WebGL context loss 后需手动刷新。移动端和多 GPU 性能尚未进行系统基准测试。
