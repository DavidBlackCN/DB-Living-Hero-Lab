## 已知限制与后续

- 轮廓仍为手工近似，未逐根处理细发丝、卷发间隙、花枝和透明花瓶；高强度照明下仍可能看见少量边缘误差。
- 法线仅表达低频方向，不能重建真实面部／衣褶几何。未恢复 albedo，原图树影和日照残留仍存在。
- 四张 4K RGBA8 贴图约 126.6 MiB，尚未进行跨 GPU 显存与帧率基准测试。
- 仍未实现眨眼、呼吸、头发运动、蒸汽或 bloom。本轮按视觉正确性优先，未扩张到微动画。
- 后续优先细化窗边复杂遮挡和发丝间隙，再制作注册准确的眨眼／轻蒸汽资产并做独立开关验证。
