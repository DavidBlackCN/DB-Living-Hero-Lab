# Blink closed candidate v1 · validation

## 结论

`blink-closed-eyes-v1.png` **不通过整图切换验收**。它与 Base 同尺寸，人物和场景大体对齐，但整张候选图存在分布广泛的像素重绘；直接在 Open / Closed 间切换会让背景、头发和衣物跟着闪动。

双眼闭合造型本身可用作**局部眼部素材来源**。一个仅覆盖双眼、边缘约 5 px 柔化的静态合成探针未发现明显接缝，但这只证明局部方案值得继续，并非最终 Blink 动画验收。当前不启用运行时 Blink，也不把候选图标记为整图可用素材。

## 输入与检查方法

- Base：`public/assets/hero/base/base-albedo.png`，1672×941，RGB。
- Closed：`public/assets/hero/blink/blink-closed-eyes-v1.png`，1672×941，RGB。
- 对齐检查：在左侧建筑区域 `x=70..779, y=120..739` 对候选图试验 ±3 px 平移；平均 RGB 绝对误差的最小值出现在 `(dx=0, dy=0)`。因此不存在可用单次平移修复的整体错位。
- 差异统计：两图约 99.2% 像素至少一个通道不同。排除近似双眼框 `x=1093..1160, y=188..238` 与 `x=1163..1232, y=207..260` 后，其余像素的平均 RGB 绝对差约 4.13；约 7.11% 的像素平均通道差大于 10。该变化遍布画面，并非仅在眼周。
- 局部探针：以闭眼图为来源，用两个椭圆区域 `x=1094..1158, y=191..236` 与 `x=1166..1230, y=211..259`、Gaussian feather 5 px 覆盖在原 Base 上。该探针仅用于可行性观察；边界和半闭眼形态尚未成为正式资产参数。

- [全画面差异图](blink-v1-difference.png)：两图平均 RGB 差异按 4 倍显示亮度；眼部最显著，背景和轮廓也有变化。
- [眼部静态三图比较](blink-v1-eye-comparison.png)：Open、整张 Closed、仅眼部 Closed 探针。
- [短切换预览](blink-v1-pulse.gif)：左侧整图方案，右侧局部探针；Open 900 ms → Closed 110 ms → Open 900 ms，循环。仅供验收观察，不代表最终时间线。

## 后续 Blink Gate

1. 从现有闭眼候选确定正式的双眼局部范围和柔边，或另制严格注册的局部闭眼透明素材。不能让脸型、刘海与背景跟随眨眼改变。
2. 补齐 Half 状态，或验证从 Open 到 Closed 的过渡方式；避免只有两帧硬切。
3. 在真实页面以正常尺寸、桌面和移动端观察多次短眨眼，检查接缝、双眼同步、频率与 `prefers-reduced-motion`。
4. 通过后才启用正式 Blink。Normal 阶段保持独立，当前不开始。
